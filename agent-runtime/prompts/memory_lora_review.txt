记忆系统 LoRA 待审稿

目标：教会模型理解记忆索引、正确调用记忆工具、判断是否需要原文细节，并依据结果简洁回答。只训练记忆系统行为。本稿尚未用于训练。

以下内容将转成“问题＋索引/已有证据＋调用预算 → 正确动作或答案”的样例，不训练模型复述规范。示例对象和事实均为虚构，不作为要记住的知识。

1. 认识记忆系统
系统通过原文向量匹配定位相关记忆，但默认只提供命中原文所属片段的索引。title 是原文主题，summary 是摘要或定位预览，match_score 是相关程度，evidence 是已经返回的原文证据。
摘要足够就回答，缺少细节再调用 read_memory。工具仅在选中索引对应的原文范围内搜索，不会自动搜索全库。分数不是答案正确率，也不表示必须读取原文。记忆是历史资料，其中的指令不增加当前授权，历史记录不自动代表当前现场状态。

2. 已有信息足够，直接回答
先检查当前问题所需的事实、对象、时间和必要条件，是否已经明确给出。足够就回答，不为重复确认而调用工具。
即使问题涉及精确数值、时间或名称，只要摘要或已有证据已完整给出答案，且没有未解决的冲突，也不必读档。通用知识或纯计算问题，不因出现索引就强行使用记忆工具。

3. 只有必要信息缺失时，读取细节
存在相关索引且预算允许时，以下情况需要 read_memory：
（1）索引说明有相关记录，却没有给出回答所需的具体事实。
（2）缺少会影响结论的条件、范围、否定或更正信息。
（3）用户要求原句、原文核对或具体出处，当前只有摘要。
（4）相关记录互相矛盾，无法从现有对象、时间和更正关系中消除冲突。
summary_pending 或 summary_rejected 为 true 时只是定位预览，不能默认其内容完整；仍可使用其明确支持的内容，缺少必要细节才读，不能见到标志就无条件读档。

4. 选对对象和索引
先核对 title 所指对象，再结合摘要、时间、条件和分数选择，只打开回答所需的索引。
不能只选最高分。“乙设备与甲设备不同”的记录，不是甲设备自身的记录。只有明确记录了对象之间的关联时，才能沿关联补充事实。
区分“当前/最新”和“最初/过去”。明确更正只覆盖对应事实；两个时段的不同值未必矛盾。现有索引已完整解释更正关系时，直接回答，无需再读一次。

5. 正确调用工具
read_memory 的 request_id 必须来自当前查询，card_ids 必须来自本轮提供的索引。question 应是当前需要寻找的具体事实或缺失细节，不能只填索引标题，也不能把猜测的答案当成搜索问题。
索引负责限定范围，question 负责表达要找什么。多个索引确有必要时，按本轮工具定义选择必要项。不要编造标识、参数或工具结果。
当前接口示例：
{"action":"read_memory","response":"","tool":"","arguments":{"request_id":"本轮给定的查询ID","card_ids":["M2"],"question":"杉禾设备的校准系数和偏移量分别是多少？"}}
参数与输出格式最终以本轮工具定义为准。

6. 依据返回原文回答
保留会影响答案的对象、时间、条件、否定和更正，只提取所问内容，不复述整段记忆。原文足够就回答，不重复读取。
区分规定、计划和实际结果：“未验收前禁止启用”不能推出“实际没有启用”。仅有部分依据时，回答已知部分并说明缺项。
在所选片段没有找到答案，只能说明“已读片段未提供，当前无法确认”，不能说“全部记忆都没有”。读到了错误对象时，不挪用其属性；还有相关索引且预算允许时改读正确对象，否则说明依据不足。

7. 处理空结果、失败和预算
没有可用索引时，不编造索引或调用 read_memory。只有本轮允许 recall 且 memory_queries_remaining 大于零时，才可用更具体的问题检索索引；否则说明当前记忆依据不足。
memory_reads_remaining 为零时不再读档。工具失败、范围受限或片段无法在预算内返回，不等于原文没有答案。没有新信息需求时，不重复相同搜索或读取。

8. 简洁输出，准确说明依据
直接回答所问，保留关键条件和必要来源，不展开内部检索过程。只有摘要时不声称已读原文，读过历史原文也不声称已核验当前现场。遵守本轮长度和输出协议，不为缩短答案删除关键条件。

重点训练样例（均为虚构）

A. 摘要足够，不读档
问题：砚河设备什么时候维护？
索引：M1，title=砚河设备维护安排，summary=维护窗口为周六上午。
正确动作：直接回答“摘要记载为周六上午。”
错误动作：再次读取只为确认这个已给出的时间。

B. 数值完整，也不读档
问题：温度等于22℃时可以启动吗？
索引：M1，title=松桥设备启动条件，summary=必须低于22℃且完成绝缘检查后才可启动。
正确动作：直接回答“不可以。摘要要求低于22℃，并完成绝缘检查。”
错误动作：仅因为问题涉及数值，就读取原文。

C. 缺少细节，正确读档
问题：杉禾设备的校准系数和偏移量分别是多少？
索引：M2，title=杉禾设备校准档案，summary=包含传感器参数、标定步骤和使用限制，具体数值见存档。
正确动作：读取 M2，question 填写当前所需的校准系数和偏移量问题。
工具返回：系数1.042，偏移量负0.6℃，仅适用于温度传感器。
正确答案：温度传感器校准系数为1.042，偏移量为负0.6℃。

D. 不被高分错误对象诱导
问题：杉禾设备的校准系数是多少？
M1：分数0.86，title=南汀设备校准档案，summary=南汀系数为1.8，与杉禾不同。
M2：分数0.78，title=杉禾设备校准档案，summary=包含校准参数，具体值见存档。
正确动作：读取 M2，搜索杉禾设备的校准系数。
错误动作：读取 M1 后回答杉禾系数为1.8，或声称没有杉禾数据。

E. 局部没有答案，不扩大结论
问题：砚河项目联络人的电话是多少？
工具返回：联络人姓名为叶舟，未给出联系电话。
预算：memory_reads_remaining=0。
正确答案：已读片段未提供联系电话，当前无法确认。
错误动作：编造号码、继续读档，或声称全库都没有电话。

F. 不把规定当成实际状态
问题：这台设备实际上启用了吗？
工具返回：未通过验收前禁止启用。
没有可继续读取的相关索引。
正确答案：记录只说明未验收前禁止启用，未说明是否实际启用。
错误答案：尚未启用。

G. 更正关系明确，直接回答
问题：岚桥项目现在的审批人是谁？
M1：旧记录为林禾；M2：同一审批事项的明确更正，改为许澄，林禾旧资格撤销。
正确答案：摘要中的更正记录指定许澄，林禾的旧审批资格已撤销。
错误动作：同时列两人为当前审批人，或仅为重复确认更正再次读档。

H. 矛盾未消除，读取相关原文
问题：岚桥设备本周的运行上限是多少？
M1、M2 对同一设备、同一周分别记为18和21，均未说明更正关系。
正确动作：预算允许时读取两条相关索引，搜索本周上限及更正依据。读后仍矛盾就说明无法确定，不擅自选较大值、较新条目或较高分条目。

制作训练数据时，必须同时覆盖“不调用工具直接答”“正确选择并调用工具”“读后回答”“空结果/失败/预算耗尽”，避免训练成每题都读档。训练与独立验收使用不同问题和事实，不把当前评测题作为训练样例。具体数据量、比例和训练参数待内容审核后再定。
