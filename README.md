## 内容概览

- **多时间尺度学习**：快系统（上下文/工作记忆）与慢系统（经验 → LoRA 权重固化）分离
- **五级记忆 L0–L4**：KV Cache → 工作记忆 → 情节记忆 → 经验/技能 → 参数化（LoRA）
- **事件驱动认知**：Salience = α·变化幅度 + β·新颖度 + γ·目标相关 + δ·风险 + ε·预测误差，LLM 只处理有意义的变化
- **增量视觉**：变化掩码 → 自适应区域 → 持久实体 → 世界坐标，配合自运动补偿
- **世界模型**：几何 + 语义统一建模，EKF 起步、因子图进阶，预测误差作为统一信号
- **Wake/Sleep 节律**：白天工作、夜间巩固（经验挖掘 → 三路路由：记忆/技能/权重）
- **安全分级 L0–L3**：硬件 > 实时控制 > 导航规则 > LLM，高层的命令永远不能覆盖底层
- **14 阶段 MVP 路线**：先验证"能否从经历中提高下次任务成功率"，再谈训练
