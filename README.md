## v3.0 当前方案

- **部署前提**：本地部署，调用费用不作为架构取舍依据。
- **三级职责**：一级执行与交接；二级组织检索、查证与综合；三级阅读历史并返回证据。
- **交接手册**：任务交接与历史索引分区，原始记录保留并可追溯。
- **原始换窗协议**：持续记账、生成手册、校验并提交状态；作为旧路径保留。当前正式一级改用上述原生 KV 压缩与继承。
- **二级约束**：事实与推断分离，保留时间、条件和冲突，说明检索范围，隔离执行权限。
- **实现顺序**：换窗连续性 → 可追溯档案 → 三级检索 → 长期运行验证 → 具身状态接入。

仓库已加入 v3.0 运行原型：[agent-runtime 使用与部署说明](agent-runtime/README.md)。原型保留 Qwen3-4B-Instruct-2507 官方 BF16 基准，当前按用户选择运行 Q4_K_M，在 Ubuntu 真机验证短上下文执行和事务交接。记忆检索现采用原文向量与关键词并行召回、轻量重排、必要上下文补齐，再由4B一次组织回答；摘要只作导航，额外读档由模型按需选择。原三级模型路径保留作对照，摘要线索、原文证据与语义核验分开标注。已手动训练并启用凝练输出 LoRA concise-v2，30 题合成配对回归的平均正文减少 25%，完整正确题数保持 28/30；两例既有问题仍在。真实具身硬件、经验提炼和自动参数固化仍为后续工作。验证范围及实际结果以运行代码中的测试和验收报告为准。

## v2.1 架构背景

- **多时间尺度学习**：快系统（上下文/工作记忆）与慢系统（经验 → LoRA 权重固化）分离
- **五级记忆 L0–L4**：KV Cache → 工作记忆 → 情节记忆 → 经验/技能 → 参数化（LoRA）
- **事件驱动认知**：Salience = α·变化幅度 + β·新颖度 + γ·目标相关 + δ·风险 + ε·预测误差，LLM 只处理有意义的变化
- **增量视觉**：变化掩码 → 自适应区域 → 持久实体 → 世界坐标，配合自运动补偿
- **世界模型**：几何 + 语义统一建模，EKF 起步、因子图进阶，预测误差作为统一信号
- **Wake/Sleep 节律**：白天工作、夜间巩固（经验挖掘 → 三路路由：记忆/技能/权重）
- **安全分级 L0–L3**：硬件 > 实时控制 > 导航规则 > LLM，高层的命令永远不能覆盖底层
- **14 阶段具身集成路线**：包含感知、定位、世界状态、经验系统与参数固化；当前记忆运行时的最小实现路线见 v3.0
